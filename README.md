# Accessible UI

Небольшая библиотека React-компонентов и хуков с фокусом на доступность (a11y). Делаю этот проект в рамках ВКР (YAP186), чтобы на практике разобраться, как в UI-библиотеках работают управление фокусом, скринридеры, навигация с клавиатуры и темы.

> Проект на старте: сейчас готов базовый каркас (сборка, линтер, тесты, токены тем), а сами хуки и компоненты ещё впереди.

## Что планируется

### 1. Темы и токены

- Простые дизайн-токены на CSS-переменных (цвета, отступы, рамки фокуса) в `src/tokens/themes.css`.
- Три темы: `light`, `dark` и `high-contrast` (с повышенным контрастом).
- Переключение через атрибут `data-theme` на корневом элементе.

### 2. Хуки доступности (ядро)

- `useFocusTrap` — удерживает фокус внутри модалок и меню, а после закрытия возвращает его обратно на кнопку-триггер.
- `useRovingFocus` — навигация стрелками внутри списков, вкладок и меню (паттерн Roving Tabindex).
- `useAnnouncer` — отправка уведомлений для скринридеров через скрытые `aria-live` области (`polite` / `assertive`).
- `useKeyboardShortcut` — удобная привязка горячих клавиш (`Esc`, `Enter`, `Space`, стрелки).

### 3. Компоненты (MVP)

- **Button / IconButton** — заметный focus ring, поддержка `aria-pressed` и аккуратная работа с `disabled`.
- **Dialog / Modal** — ловушка фокуса, закрытие по `Esc`, возврат фокуса после закрытия.
- **Select / Dropdown** — выбор стрелками и с клавиатуры, `aria-expanded`, `aria-activedescendant`.
- **Tabs** — переключение вкладок стрелками по стандарту WAI-ARIA.
- **Toast** — всплывающие уведомления, связанные со скринридерами через `aria-live`.
- **Tooltip** — подсказки с задержками, `aria-describedby` и закрытием по `Esc`.

### 4. Проверка качества и витрина

- **Storybook** с аддоном `@storybook/addon-a11y`, чтобы смотреть компоненты вживую и сразу проверять контраст и ARIA-дерево.
- **Vitest + React Testing Library + `vitest-axe`** — автотесты на поведение с клавиатуры и базовые проверки по WCAG 2.1.

## Стек

- **React 19** + **TypeScript**
- **Vite** (режим библиотеки) + `vite-plugin-dts` для генерации типов
- **Tailwind CSS 4** + CSS Variables
- **Floating UI** (`@floating-ui/react`) для позиционирования всплывающих элементов
- **Storybook** + `@storybook/addon-a11y`
- **Vitest**, **Testing Library**, **vitest-axe**
- **ESLint** (включая `eslint-plugin-jsx-a11y`) + **Prettier**

## Структура

```text
src/
├── components/   # будущие UI-компоненты
├── hooks/        # будущие хуки доступности
├── styles/       # общие стили (globals.css)
├── tokens/       # CSS-переменные и темы (themes.css)
└── index.ts      # точка входа библиотеки
```

## Команды

Установка зависимостей:

```bash
npm install
```

Сборка библиотеки:

```bash
npm run build
```

Запуск тестов:

```bash
npm test
```

Линтер и форматирование:

```bash
npm run lint
```

Запуск Storybook (понадобится после настройки конфига `.storybook`):

```bash
npm run storybook
```
